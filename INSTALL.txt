FAB SELLER BLOCKLIST
Chrome, Edge, Brave, Opera (Chromium). Firefox/Safari not supported.

INSTALL
1. Extract the ZIP and keep the folder.
2. Open your browser's Extensions page. Enable Developer mode.
3. Click Load unpacked. Select the folder containing manifest.json.

USE
Hover a seller's name -> Block.
Toolbar icon -> manage sellers, keywords, import/export.
