Fab Seller Blocklist  (v0.1.0)
Hides listings on fab.com from sellers or keywords you choose. Unofficial, not affiliated with Epic Games.
Lists are stored in your browser's extension storage. Syncing depends on browser settings.

BROWSERS
Designed for Chromium browsers, including Chrome, Edge, Brave, and Opera.
Firefox and Safari are not currently tested or supported.

INSTALL (Chromium browsers)
1. Unzip this file somewhere permanent (e.g. Documents\fab-seller-blocklist). Do not delete the folder afterwards.
2. Go to  chrome://extensions   (edge://extensions on Edge)
3. Turn on "Developer mode" (top right)
4. Click "Load unpacked" and select the unzipped folder
5. Open https://www.fab.com and browse as usual

USE
- Hover a seller name on any card -> click "Block". The page reloads without that seller.
- Toolbar icon -> popup: manage blocked sellers, add keywords (e.g. "metahuman" hides any
  listing whose title contains it), import/export lists, toggle the auto-reload.
- Blocked cards never download their thumbnails.

NOTES
- Chrome shows a "Disable developer mode extensions" prompt on startup. Click "Keep" or close it.
- If Fab changes its page layout the filter may stop working until updated.
